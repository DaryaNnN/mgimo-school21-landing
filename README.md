# МГИМО × Школа 21 – лендинг магистратуры

Адаптивный одностраничный сайт программы «Управление цифровыми продуктами на международных рынках».

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## GitHub Pages

В `vite.config.js` для сборки с `GITHUB_PAGES=true` задан `base: '/mgimo-school21-landing/'`. Репозиторий GitHub должен называться `mgimo-school21-landing`, либо необходимо изменить `base` на фактическое имя.

GitHub Actions собирает и публикует сайт после push в `main`. Источник Pages — GitHub Actions. Проверки и ограничения описаны в `QA.md`.

## Источники и статус

Контент подготовлен по официальным страницам:
- https://mgimo-pm.21-school.ru/
- https://pk.odin.mgimo.ru/master/21

Цены и подробности относятся к опубликованным условиям; при подготовке к реальному запуску нужно уточнить актуальные сведения.

**Учебный независимый дизайн-концепт.** Не является официальным сайтом университета и не собирает персональные данные. Использование официальных брендов и фотографий требует отдельной проверки прав на материалы.

## Изображения преподавателей

Карточки используют типографические заглушки. Для подключения реальных портретов разместите согласованные файлы в `public/images/teachers/` и добавьте пути в массив `teachers` файла `src/App.jsx`. Имена реальных преподавателей нельзя подменять сгенерированными портретами.
